NDVI & Spectral Vegetation Indices

Vegetation indices measure plant health using spectral reflectance differences across red and Near-Infrared (NIR) light bands. Healthy plants strongly absorb Red light for photosynthesis while strongly reflecting NIR light from cell structures.

Code Snippets (Python & Google Earth Engine)

Python (Rasterio & GeoPandas) 
import rasterio

with rasterio.open('sentinel2_image.tif') as src:
    red = src.read(4).astype('float64')
    nir = src.read(8).astype('float64')

    # Calculate Normalized Difference Vegetation Index
    ndvi = (nir - red) / (nir + red + 1e-10)
    print("Calculated NDVI max:", ndvi.max())

var s2 = ee.ImageCollection('COPERNICUS/S2_SR')
